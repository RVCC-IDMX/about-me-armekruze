## Description

This project, titled **“Web Dev 1: About Me,”** serves as a Personal Portfolio Website deployed on Netlify. Its purpose is to demonstrate foundational Web Development I skills by creating a multi-section, navigable personal webpage.

## Learned Skills

### Overall Structure & Navigation
- Using HTML structure elements (`nav`, `section`, `header`, `footer`)
- Creating anchor links (`<a>`) for smooth navigation (Bio, Gallery, Blog, Contact)
- Establishing a clear document hierarchy

### Biography & Hobbies
- Structuring content with headings (`h2`), lists (`ul`, `li`), and paragraphs (`p`)
- Ensuring readability and logical content flow

### Photo Gallery & Media
- Embedding images using the `<img>` tag
- Applying responsive principles for image scaling
- Writing descriptive alt text for accessibility

### Contact Form Implementation
- Building complex HTML forms
- Using various input types (`text`, `email`, `tel`)
- Implementing radio buttons and a `<select>` menu
- Applying required-field validation

### Styling & Layout
- Applying basic CSS for consistent layout and presentation
- Establishing and applying a color palette

### Deployment
- Understanding and using continuous deployment with Netlify
- Deploying local code to a live, publicly accessible site
